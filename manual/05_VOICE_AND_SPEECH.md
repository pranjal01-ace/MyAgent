# 🎙️ Voice & Speech System Manual

This document details the text-to-speech (TTS) synthesis engine, speech-to-text (STT) transcription engine, sentence-level audio streaming, instant barge-in interruption, and voice REST endpoints under `backend/voice/` and `backend/speech/`.

---

## 1. Text-to-Speech Engine: `backend/voice/service.py`

**File Location:** [`backend/voice/service.py`](file:///D:/Ace_Ai/backend/voice/service.py)

### Class: `TTSEngine`
Provides low-latency speech synthesis supporting Microsoft Edge-TTS with fallback to Windows SAPI5 (`pyttsx3`) and Pygame audio playback.

#### Architectural Features
1. **Sentence Streaming:** Plays individual complete sentences sequentially as they are generated by the LLM, reducing latency from ~3-5 seconds to <800ms.
2. **Instant Barge-In:** When the user interrupts (speaks or clicks interrupt), playback terminates instantly, audio buffers are cleared, and the `_interrupted` flag aborts subsequent sentences.
3. **Dual Backend Engine:**
   - **Primary:** `edge-tts` generating high-fidelity neural audio (`en-US-ChristopherNeural` or configured voice).
   - **Fallback:** Offline Windows SAPI5 (`pyttsx3`) if internet connectivity is interrupted.

#### Method Reference

##### `speak(text: str, block: bool = False) -> float`
* **Parameters:**
  - `text`: Text string to synthesize and play.
  - `block`: If `True`, blocks calling thread until playback completes. Defaults to `False` (background thread playback).
* **Behavior:**
  - Cleans markdown formatting, code blocks, and emojis before synthesis.
  - Generates audio in a temporary file and plays via `pygame.mixer`.
* **Returns:** Approximate playback duration in seconds.

##### `stop() -> None`
* **Purpose:** Instant barge-in cancellation.
* **Behavior:**
  - Sets `_interrupted = True`.
  - Immediately stops `pygame.mixer.music`.
  - Cleans up active audio files.

##### `is_speaking() -> bool`
* **Returns:** `True` if audio is actively playing through the sound output device, `False` otherwise.

## 2. Speech-to-Text Engine: `backend/speech/stt_engine.py`

**File Location:** [`backend/speech/stt_engine.py`](file:///D:/Ace_Ai/backend/speech/stt_engine.py)

### Class: `STTEngine`
Captures microphone audio and transcribes spoken user prompts:

#### Method Reference

##### `listen_and_transcribe(timeout: int = 5, phrase_time_limit: int = 12) -> str`
* **Parameters:**
  - `timeout`: Maximum seconds to wait for user to start speaking.
  - `phrase_time_limit`: Maximum seconds allowed for a single spoken sentence.
* **Behavior:**
  - Performs dynamic ambient noise calibration with energy threshold adjustment.
  - Captures microphone audio stream.
  - Transcribes audio via Whisper / Google Speech API.
* **Returns:** Recognized text string, or empty string `""` if silence or unrecognized.

| Method | Endpoint | Request Body | Response | Description |
| :--- | :--- | :--- | :--- | :--- |
